# 接码池页面与操作设计

本功能扩展现有石墨蓝工作台。管理员维护全局国家报价与凭据，普通 CDK 仅选择接码池并知晓成功扣次。用户已确认手机验证码通过即收费，池内统一费率；后续 OAuth 结果不改变已完成接码的费用。

## 页面方向

使用现有 IBM Plex Sans / Noto Sans SC 字体与主题。页面灰 #f3f5f8、表面白 #ffffff、文字 #202a3b、操作蓝 #365edb、成功绿 #1a7353、提醒棕 #916015。标题 24px，正文 13–14px，辅助 11–12px，金额使用等宽数字。浅深色均用现有变量。

```text
接码池                              刷新  添加国家报价
今日取号 | 今日成功 | 成功实际金额 / 报价估算
国家报价 | 取号记录 | 每日统计 | 设置
搜索国家、服务商  状态筛选
国家 / 服务商 | 价格上限 | 状态 | 累计取号与成功
优先级与启停操作
```

国家报价是主体，服务商凭据与规则收在设置页，旧订单处理折叠展示；手机表格转带标签的行。全部内容左对齐。复用既有图标、焦点、主题与弹窗，今日数字与金额使用紧凑信息带。

## 操作与状态

- 管理员保存服务商凭据，查询报价后可多选国家与价格加入池。查询仅请求报价，不购买号码。
- 保存国家、价格上限、币种、供应商路由、优先级和启停；报价不冒充实付。
- 条目状态为可用、冷却、停用、凭据异常、恢复尝试中。手动停用不自动开启。
- 普通 CDK 在接码配置选择池，看到单价、可用状态和预留规则，不返回管理员密钥。
- 目标服务确认手机验证成功后扣次。取号、收到短信和提交验证码均不等于成功。
- 开始时预留；明确失败释放；验证结果不明保留预留进入管理员核实。重复通知和恢复只结算一次。
- 连续明确无号默认 3 次暂停 10 分钟，冷却后由单个真实任务试用；网络错误与收码超时不计无号。
- 优先级越小越先用，同级轮询；中央状态跨 CDK 共用。池内换号属于同次操作，不重复收费。
- 已分配订单固定凭据与配置，管理员修改规则仅影响新操作。

## 预览

`web/sms-pool-preview.html` 使用独立演示适配器，无 CDK 或接码 API 调用。所有演示记录使用保留域名 example.invalid，头部持续标记演示状态。生产组件使用真实接口，不加载演示数据。

## 正式功能

正式入口为主工作台。管理员在侧栏进入“接码池”，配置服务商凭据、国家报价、统一收费与暂停规则；普通 CDK 在接码平台配置选择“接码池”。新池默认关闭，配置完成后由管理员开放。

接码订单和计费操作在中央保存。操作流水分别记录所属 CDK 与真实操作者；管理员代操作仍从所属普通 CDK 扣次。导入恢复保存操作者，历史无操作者的恢复明确记为系统恢复。接码记录支持服务端分页，未知结果在管理员核实后同步回任务，无需重启。

SMSBower 档位筛选同时保留精确供应商编号；未标级报价不改称 Silver 或 Bronze。凭据余额不足或限流按同 Key 联动暂停，更新备注不会清除退避；充值后可明确恢复。等待取号租约或并发名额期间取消，后台不再购买号码。

校验包括中央池与账本、权限和价格确认、跨 CDK 并发、实际协议的私有验证证据、取消和重启、页面分页及操作确认。测试只使用虚构账号和本地服务商。主服务启动另外检查健康、主页、资源、匿名接口保护，以及已有账号、CDK 余额和 OAuth 文件的保留情况。

## 按需取号与旧订单收尾

### 分类与收费

管理员可以自建分类，初始为“美区”和“其他”。每类保存固定 ID、显示名称、成功扣次、费率版本、启用状态及归档时间；每条国家报价属于一个分类，同一路由可在不同分类独立添加。服务商凭据、请求队列和按 Key 的限流仍共用。取号及换号仅在所选分类内选路，不允许无号时自动跨分类。

普通 CDK 配置保存所选分类 ID。导入与接码确认同时显示分类名称、单次扣次及最高合计；服务端按分类读取费率并校验确认版本。操作开始时冻结分类名与费率，同一个操作 ID 不能切分类；已有操作在改价后按原费率结算，未开始且确认费率过期的任务需重新确认。停用或归档阻止新购号，已发出的请求和已分配号码可以继续完成。结果待核实不能切类重复购号。

已有国家报价与全局费率迁入“其他”，“美区”默认停用；旧操作沿用旧费用，未分类历史成本标为“原接码池”。归档代替硬删除，报价移动、分类改名均不改历史快照；同供应商账号、同订单的去重身份不包含分类。取号记录、每日统计及费用明细支持分类过滤，并保持费用与普通用户数据的权限边界。

任务实际进入手机号步骤后才创建取号请求。启用的国家报价按优先级选择，同级轮询；无号尝试下一条，等待中的任务按有界重试策略继续。后台不预购，不维护库存目标，旧自动补满配置不再生效。

业务任务并发与服务商请求并发分开。请求并发默认为 3，同服务商账号仍独占请求；收到取号结果后释放请求名额，等待短信、验证码提交和结果待核实不占用名额。CDK 归属、费用预留、同任务操作幂等、撤权检查和成功证据结算保留。排队期间停止不发起购买；在途请求的返回结果必须落账，未知结果不重复购买。

历史库存表继续保存旧订单和取消收尾。已分配订单继续处理，未分配旧号码进入取消队列；换号或明确失败的直接购号订单也持久排队，遵守最早允许取消时间。取消请求、取消确认、退款确认分别保存，原取消原因保留。未知购号进入核实，已结束订单不重新打开。

管理员默认查看国家报价，旧订单处理折叠在设置中。普通 CDK 仅看到池开关、按需取号可用状态和成功费用，不包含国家、报价、供应商或内部条目数量。

## 管理员费用查看

管理员在取号记录和旧订单处理中查看每个号码的服务商购号金额；接码记录可展开每次换号的订单费用，CDK 扣次单独显示。只有服务商订单返回且来源标记为 `order` 的金额才计为确认购号额，零金额有效。报价和价格上限另行标注；旧订单未返回实付时显示未知，币种缺失时不推测币种。

全量历史按币种分别精确累加，同一服务商账户和订单在缓冲分配与任务流水中只计算一次。取消确认与退款确认分别保留；退款待核实额单独列出，不据此抵扣购号额，因此购号金额不代表最终净成本。普通 CDK 的接口与页面不返回或展示这些费用、报价、国家和服务商明细。

## 导入与接码合并确认

单个和批量导入选择自动接码池时，仅展示一次确认：服务端去重后的新增与已有账号、入库扣次、手机验证成功扣次及最高合计在同一弹窗列出。新增账号仍按原规则扣导入次数，接码成功另按池规则扣次；最高合计不是立即预留或扣除的金额。余额不足以支持全部账号接码时提示可支持的数量，实际取号仍逐个检查预留。

合并确认提交当前读取的池费率，取消或按 Escape 保留原输入且不创建任务。手动导入、自有接码服务只确认导入费用；已有账号单独开始接码仍只确认接码池费用。

## 筛选与成功成本统计

管理员国家报价支持状态、国家、服务商、凭据和取号记录等筛选；取号记录支持结算状态、国家、服务商、凭据、费用是否确认及日期筛选，过滤先于分页。

“每日统计”按服务商账号与订单 ID 去重。取号指真实返回有效号码及订单，无号请求不计入；成功只认目标服务确认手机验证通过，失败换号分别计取号，仅最终成功订单计成功金额。固定北京时间自然日：取号按 createdAt，成功和成功金额按 verifiedAt。默认展示最近 30 天并补齐零记录日期，今日概览不受日期筛选影响。缺失可信成功时间的旧记录不伪造日报日期。

国家报价显示当前路由累计花费、取号数和成功数，服务商凭据显示历史累计；修改路由后旧国家与旧报价快照保留。每日统计支持日期、国家和服务商筛选，并保留国家、服务商、报价条目分组。成功金额分别展示确认实付和报价估算；没有订单实付时才使用购号时的报价快照，不用最高价推算。未知币种的报价按服务商分开展示，退款待核实不抵扣金额。

国家编码在不同平台可能相同，统计按服务商与国家编码联合识别，保留购号当时的路由元数据。实际费用、币种或历史来源缺失时显示未知数量，不用报价上限补金额；不同币种分别汇总，退款待核实不抵扣总花费。所有扩展统计只提供给管理员。
