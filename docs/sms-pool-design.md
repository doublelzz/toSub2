# 接码池页面与操作设计

本功能扩展现有石墨蓝工作台。管理员维护全局国家报价与凭据，普通 CDK 仅选择接码池并知晓成功扣次。用户已确认手机验证码通过即收费，池内统一费率；后续 OAuth 结果不改变已完成接码的费用。

## 页面方向

使用现有 IBM Plex Sans / Noto Sans SC 字体与主题。页面灰 #f3f5f8、表面白 #ffffff、文字 #202a3b、操作蓝 #365edb、成功绿 #1a7353、提醒棕 #916015。标题 24px，正文 13–14px，辅助 11–12px，金额使用等宽数字。浅深色均用现有变量。

```text
接码池                              刷新  添加国家报价
已开放  可用条目 / 冷却条目          验证成功扣 N 次
国家报价 | 服务商凭据 | 接码记录       池规则
搜索国家、服务商  状态筛选             开放开关
国家 / 服务商 | 价格上限 | 状态         成功扣次
优先级与启停操作                       连续无号暂停
                                     尝试 / 并发上限
                                     保存池规则
```

国家报价是主体，规则为右侧常驻栏；中屏规则移至列表下方，手机表格转带标签的账号行。全部内容左对齐。复用既有图标、焦点、主题与弹窗，不增加装饰统计卡片。设计审查删除了大号指标和通用卡片，改用国家报价与冷却恢复时间作为视觉重点。

## 操作与状态

- 管理员保存服务商凭据，查询报价后可多选国家与价格加入池。查询仅请求报价，不购买号码。
- 保存国家、价格上限、币种、供应商路由、优先级和启停；报价不冒充实付。
- 条目状态为可用、冷却、停用、凭据异常、恢复尝试中。手动停用不自动开启。
- 普通 CDK 在接码配置选择池，看到单价、可用状态和预留规则，不返回管理员密钥。
- 目标服务确认手机验证成功后扣次。取号、收到短信和提交验证码均不等于成功。
- 开始时预留；明确失败释放；验证结果不明保留预留进入管理员核实。重复通知和恢复只结算一次。
- 连续明确无号默认 3 次暂停 10 分钟，冷却后由单个真实任务试用；网络错误与收码超时不计无号。
- 优先级越小越先用，同级轮询；中央状态跨 CDK 共用。池内换号属于同次操作，不重复收费。
- 已分配订单固定凭据与配置，管理员修改规则仅影响新操作。

## 预览

`web/sms-pool-preview.html` 使用独立演示适配器，无 CDK 或接码 API 调用。所有演示记录使用保留域名 example.invalid，头部持续标记演示状态。生产组件使用真实接口，不加载演示数据。

## 正式功能

正式入口为主工作台。管理员在侧栏进入“接码池”，配置服务商凭据、国家报价、统一收费与暂停规则；普通 CDK 在接码平台配置选择“接码池”。新池默认关闭，配置完成后由管理员开放。

接码订单和计费操作在中央保存。操作流水分别记录所属 CDK 与真实操作者；管理员代操作仍从所属普通 CDK 扣次。导入恢复保存操作者，历史无操作者的恢复明确记为系统恢复。接码记录支持服务端分页，未知结果在管理员核实后同步回任务，无需重启。

SMSBower 档位筛选同时保留精确供应商编号；未标级报价不改称 Silver 或 Bronze。凭据余额不足或限流按同 Key 联动暂停，更新备注不会清除退避；充值后可明确恢复。等待取号租约或并发名额期间取消，后台不再购买号码。

校验包括中央池与账本、权限和价格确认、跨 CDK 并发、实际协议的私有验证证据、取消和重启、页面分页及操作确认。测试只使用虚构账号和本地服务商。主服务启动另外检查健康、主页、资源、匿名接口保护，以及已有账号、CDK 余额和 OAuth 文件的保留情况。

## 全局号码缓冲

缓冲是管理员共享的未分配号码库存，与普通 CDK 的接码任务和计费操作分开保存。日常只配置“缓冲目标数量”和“自动补满”。所有加入并启用的国家报价自动参与轮流取号，一条报价可以连续供应多个号码；系统按全局库存缺口持续补满，不再受每报价一个号码、低水位和空闲需求的限制。

“立即补满”启动一个独立后台补货任务并立即返回进度；有货时连续处理，全部来源暂时无号时等待 5 秒再试。重复点击复用当前任务。一次手动任务达到目标后结束，自动补满开启时则在库存减少后继续补充。进度显示目标、可用、正在购号、待补和受阻原因；同一报价的失败按原因聚合，原始明细折叠查看。

“暂停补号”关闭自动和手动补货，保留已有号码及已发出购买请求的有效返回结果；“回收未分配号码”先暂停补号，再回收未分配订单，购号中的返回结果也进入回收。系统自动管理调度和限速，未知、重复及取消结果不明的订单触发独立保护并显示原因。

- 预取不预留和扣除普通 CDK 次数。领取前检查订单仍在等待短信，数据库事务中独占分配并绑定任务；成功收费沿用原账本。
- 缓冲为空或不可用时继续即时取号。等待用户请求优先于补货，不因库存目标阻止原有接码。
- 已分配号码不返共享库存，也不占待分配缓冲目标。临期、停用与手动回收只处理未分配号码，正在验证的订单继续独立完成；单纯暂停补货不回收。
- 有效期优先使用服务商返回时间。旧文本接口使用该服务商短激活期限作保守估算，标记 `provider_policy`，不会冒充接口确认期限；取消等待从收到号码后起算。
- 补货不提前调用号码就绪操作。领取前已到码、状态不明确或规范化手机号重复时隔离，不把旧短信交给另一个 CDK。
- 取消请求、取消确认、退款确认分别保存。严格取消回执不代表退款到账。未知购号、取消未确认和隔离订单计入独立异常订单保护；重启不重放未知购号。
- 普通 CDK 仅看到接码池开关、是否有号码、是否正在补货、可否即时取号和成功费用。API 及任务摘要不包含池内国家、报价、条目数或供应商明细。

管理员默认打开“号码库存”，显示完整可复制号码、购号时国家快照、实付金额或待确认报价、状态及剩余有效期。列表区分当前和历史，所有筛选在服务端分页前执行，不把无号码的失败尝试当成库存。完整号码仅由管理员库存接口返回，普通 CDK 摘要和统计记录维持各自权限边界。设置、凭据和历史成本移至相应页签，沿用现有视觉体系。页面中的演示库存与正式数据库完全独立。

## 管理员费用查看

管理员在号码缓冲和接码记录查看每个号码的服务商购号金额；接码记录可展开每次换号的订单费用，CDK 扣次单独显示。只有服务商订单返回且来源标记为 `order` 的金额才计为确认购号额，零金额有效。报价和价格上限另行标注；旧订单未返回实付时显示未知，币种缺失时不推测币种。

全量历史按币种分别精确累加，同一服务商账户和订单在缓冲分配与任务流水中只计算一次。取消确认与退款确认分别保留；退款待核实额单独列出，不据此抵扣购号额，因此购号金额不代表最终净成本。普通 CDK 的接口与页面不返回或展示这些费用、报价、国家和服务商明细。

## 导入与接码合并确认

单个和批量导入选择自动接码池时，仅展示一次确认：服务端去重后的新增与已有账号、入库扣次、手机验证成功扣次及最高合计在同一弹窗列出。新增账号仍按原规则扣导入次数，接码成功另按池规则扣次；最高合计不是立即预留或扣除的金额。余额不足以支持全部账号接码时提示可支持的数量，实际取号仍逐个检查预留。

合并确认提交当前读取的池费率，取消或按 Escape 保留原输入且不创建任务。手动导入、自有接码服务只确认导入费用；已有账号单独开始接码仍只确认接码池费用。

## 筛选与成功成本统计

管理员国家报价支持状态、国家、服务商、凭据和取号记录等筛选；号码缓冲支持库存状态和来源筛选；接码记录支持结算状态、国家、服务商、凭据、费用是否确认及日期筛选，过滤先于分页。

“成本统计”按全量历史中唯一服务商订单统计，缓冲号码分配给任务时不再重复计数。分别显示成功取号数、手机验证通过数、全部已确认购号金额、验证通过号码的已确认金额。成功取号指服务商实际返回号码及订单，不是尝试次数；验证码通过只认最终验证成功的号码，失败换号不计入验证通过成本，但其购号额仍计入总花费。

国家报价显示当前路由配置的累计花费、取号数及验证通过数，服务商凭据显示该凭据的历史累计；管理员修改国家或价格后，旧路由数据仍保留在历史成本统计中，多次变更的报价条目标注“历史多路由”。统计页可按国家、服务商或报价条目分组，支持购号日期、国家、服务商、凭据、结果和费用状态筛选；接码记录的日期则按操作创建时间筛选。

国家编码在不同平台可能相同，统计按服务商与国家编码联合识别，保留购号当时的路由元数据。实际费用、币种或历史来源缺失时显示未知数量，不用报价上限补金额；不同币种分别汇总，退款待核实不抵扣总花费。所有扩展统计只提供给管理员。
