# CDK 实际接入设计记录

日期：2026-10-23。对象：接入真实后端的 toSub2 应用；验证环境为本机隔离数据目录与合成账号。

## Overview

本次扩展保留现有“侧栏工作台”：石墨中性色、蓝色主动作、连续概览带、细分隔线表格，以及配置与详情抽屉。根目录 `DESIGN.md`、`.impeccable/design.json`、`web/src/styles.css` 和 `web/src/workspace.css` 继续承担全局视觉依据；本文记录 CDK 功能的实际组合与局部取值。

应用入口由 `web/src/main.jsx` 接入 `CdkGate.jsx`，登录后的 CDK 管理、我的 CDK 与安全中心由 `CdkWorkspace.jsx` 提供，顶部当前 CDK 的查看与复制由 `CurrentCdk.jsx` 提供，局部样式在 `cdk.css`，配置保存和导入确认由 `cdk-api.mjs` 协调。后端已经接入鉴权、会话、SQLite、次数、融合和访问保护；这些功能的本机合成验证与真实生产账号操作分别陈述。

本目录 `index.html`、`page-design.md`、`design-system-notes.md`、`verification.md` 保留为先前原型及评审快照。原型中“尚待后端接入”的描述属于其验证时点，当前实施状态另见实际接入记录。

## Colors

CDK 页面直接使用现有 CSS 变量，没有复制原型的 `--accent` 命名或建立新的全局色板。

| 用途 | 实际变量 | 浅色 / 深色 |
|---|---|---|
| 工作区 / 内容表面 | `--page` / `--surface` | `#f3f5f8` / `#ffffff`；`#131923` / `#1b2331` |
| 正文 / 辅助文字 | `--ink` / `--muted` | `#202a3b` / `#5f6c80`；`#edf2f9` / `#a4b0c3` |
| 分隔线 | `--line` | `#e1e6ef` / `#334156` |
| 主动作 / 悬停 / 选择表面 | `--green` / `--green-strong` / `--green-soft` | `#365edb` / `#294dbb` / `#eaf0ff`；`#8daeff` / `#abc3ff` / `#293952` |
| 成功 / 错误 / 警告文字 | `--success` / `--danger` / `--amber` | 沿用现有主题语义色，并同时显示文字 |
| 错误 / 警告表面 | `--danger-soft` / `--amber-soft` | `#fff0f1` / `#fff6df`；`#402831` / `#3b3326` |

历史变量名 `green` 在本应用中仍表示蓝色。原型中更浅的局部表面和不同警告底色未搬入实际应用；状态“正常 / 已禁用 / 已融合”、失败次数、封禁结果都保留可读文字。

## Typography

字体继承 `"IBM Plex Sans", "Noto Sans SC", "Segoe UI", "Microsoft YaHei", sans-serif` 本机回退栈，没有新增字体下载。正文 14px、页面标题 24px / 600、表单与按钮 13px、辅助标签 12px、表格次要信息 11px。手机页面标题随工作区样式降为 22px。

CDK 登录标题为 34px / 600，手机为 28px；CDK 概览与次数等式使用 25px / 500，手机为 23px；我的 CDK 主余额为 34px / 500。次数采用 `tabular-nums`，标识、客户端 IP 与完整 CDK 结果采用现有等宽字体栈。表格标识允许长串换行；当前 CDK 使用单行只读输入，支持选择复制。该输入默认 12px，粗指针设备为 16px。

## Layout

真实工作区继承最大宽度 1920px、桌面 176px 侧栏和默认 28px 水平留白。CDK 管理的统计是连续信息带；我的 CDK 在宽屏以余额与流水、融合表单两列排列；安全中心以文字标签切换日志、黑名单和保护规则。

| 条件 | 实际变化 |
|---|---|
| 至少 1600px | 工作区水平留白增至 40px |
| 不超过 1100px | 侧栏收至 152px，工作区水平留白 22px；我的 CDK 两列转单列 |
| 不超过 900px | 侧栏转可换行顶部导航，页脚隐藏；登录两列变为弹性说明列与 370px 表单，间距 35px |
| 不超过 640px | 工作区水平留白 13px；登录转单列，表单内边距 24px；身份条独占一行，操作组与筛选允许换行，双列表单转单列 |
| 不超过 640px 的 CDK 管理 | 主表保留标识、可用次数和详情；备注与非正常状态并入标识摘要，追加及完整指标从详情访问 |
| 不超过 640px 的安全日志 | 独立“次数 / 结果”列折叠，其内容移到验证事件单元格；事件时间和处理、拉黑入口保留 |
| 不超过 640px 的流水 | 保留事项、变化和余额，折叠时间及全局流水中的 CDK 列 |
| 粗指针设备 | 现有按钮与导航、CDK 行操作、标签、筛选和表单控件具有至少 44px 点击高度；相关输入为 16px |

登录内容最大宽度 980px，桌面两列为弹性说明列与 420px 表单、间距 85px。手机隐藏独立规则列表，保留标题下的扣次说明。页面最小宽度为 320px。实际表格使用固定布局、可收缩列与长串换行；响应检查同时检查页面宽度和表格是否宽于容器。

当前 CDK 的眼睛与原脱敏身份按钮并排。浮层定位在该组合下方 9px，桌面右对齐，宽度不超过 390px 或视口减 32px；640px 以下左对齐，宽度不超过视口减 26px。粗指针下复制按钮与完整值输入高度至少 44px，输入文字为 16px；不能只通过缩窄桌面视口判断触控样式。

## Elevation & Depth

静态概览和表格保持平面，使用表面色与分隔线组织。系统配置及管理详情复用现有右侧抽屉，阴影为 `-10px 0 30px var(--shadow)`，遮罩为 `var(--backdrop)`。

导入的最终次数确认使用专用居中确认层，宽度不超过 480px 或视口减 32px，并限制高度、允许内容内部滚动。其局部阴影为 `0 14px 45px rgb(20 34 57 / 20%)`；该取值属于 CDK 确认组件，未改写全局阴影 token。原有导入表单和配置抽屉保留各自布局。

当前 CDK 使用无背景遮罩的非模态浮层，复用表面、文字、边界和输入底色，内边距 16px、圆角 10px。局部阴影为 `0 12px 32px rgb(20 34 57 / 16%)`，没有增加全局 token。

没有新增入场或主题切换动画。加载图标沿用旋转动画，减少动态效果偏好由现有工作区覆盖处理。

## Shapes

按钮、输入、身份条与错误提示使用 8px 圆角；表格、登录表单、融合表单与导入确认使用 12px 圆角。现有业务抽屉贴右且无外圆角，标准宽度上限 460px，CDK 管理及系统配置调用宽抽屉上限 660px，均不超过视口。

## Components

| 组合 | 真实行为与状态 |
|---|---|
| CDK 登录 | 密码型输入、验证中禁用和就地错误；初次 bootstrap 完成前同样显示忙碌状态。来源封禁后改为受限状态及重新检查入口，不提供可提交的 CDK 输入 |
| 初次工作区加载 | 管理、我的 CDK、安全中心首次读取完成前显示“正在加载当前工作区”与 `role="status"`；请求错误显示文字，避免把尚未加载的数据当作零值或空记录 |
| 管理视角 | 管理员默认进入 CDK 管理；统计、搜索、状态筛选、生成、追加、详情流水、备注、启停、轮换和待恢复导入均接真实接口。列表只显示脱敏标识 |
| 管理员自身用户视角 | 顶部“切换用户视角”收起管理入口并进入原账号授权工作台；管理员自身工作区保持不限次数，可通过“返回管理视角”返回 |
| 显式目标 CDK 工作区 | 从 CDK 详情进入时调用后端工作区切换，刷新会话 token 与配置并重建当前应用；顶部范围提示说明操作和新增导入归属所选 CDK，余额按该工作区显示；返回管理视角时恢复管理员自身工作区 |
| 普通用户导航 | 提供账号授权、MFA 修改、我的 CDK、配置；管理入口由真实身份决定。顶部身份条显示当前脱敏标识与剩余次数 |
| 查看当前 CDK | 脱敏身份按钮仍打开“我的 CDK”，旁边眼睛单独展开非模态浮层。展示读取中、完整只读值、复制及复制成功状态；复制失败时选择输入内容并提示手动复制。眼睛再次点击、关闭按钮、Escape、外部点击、页面隐藏或打开满 60 秒时关闭并清除明文，Escape 后焦点返回眼睛 |
| 系统配置 | 保留接码平台、邮件 API、Sub2API、代理 IP 及各自原有配置入口。普通用户标题为“工作区配置”，管理员为“系统配置”；抽屉明确当前 CDK 范围 |
| 导入确认 | 服务端预览去重后的新增、更新、预计扣次及扣后余额；三段等式和最终按钮明确本次消耗。已有账号更新不重复扣次；余额不足阻止提交；管理员自身显示“不限” |
| 我的 CDK 与融合 | 余额、累计消耗、账号数和状态分别显示。验证来源后才出现转入等式；编辑来源立即清除旧预览；最终抽屉要求确认来源永久失效，提交再次核对预览指纹。管理员工作区及代看状态不提供融合操作 |
| 生成与轮换结果 | 当前批次的完整 CDK 在结果抽屉支持复制、下载及复制失败后的手动选择，关闭即移除该结果；后续列表和详情保持脱敏。当前工作区的完整值另经顶部眼睛按需读取 |
| 安全中心 | 安全日志、IP 黑名单、访问保护规则三个标签；真实失败记录可处理或转入拉黑表单；手动封禁可选择临时或永久；保护规则提供可编辑字段和保存反馈 |
| 错误与配置保存 | 错误使用 `role="alert"`，操作成功使用 `role="status"`；配置保存失败出现置顶错误及重新保存入口，退出和切换工作区先等待当前配置保存 |

配置由服务端按 CDK 加密保存，登录或切换时载入当前范围。代理、接码、邮件和 Sub2API 的操作配置改经工作区适配层读取与保存；管理员自身工作区可迁移原有浏览器配置，保存成功后移除对应旧本地键。其他 CDK 不继承这些配置。主题等非业务配置继续沿用现有机制。

完整 CDK 通过需会话与 CSRF 的 `POST /api/cdk/reveal` 读取，以服务器当前工作区为范围。管理员进入其他 CDK 工作区时读取所选工作区的密钥，返回自身后恢复自身范围。完整值经现有 vault 加密保存，在初始化、生成、轮换和成功登录时维护；旧版仅有摘要的数据需要成功验证当前 CDK 一次后补存。验证其他 CDK 不会改变当前范围。浏览器不将完整值写入 `localStorage`，浮层关闭后清空组件明文状态并中止未完成读取。

抽屉及导入确认使用现有 React 对话层与 `role="dialog"`、`aria-modal="true"`，提供标题、焦点限制、关闭后焦点恢复与 Escape。嵌套导入确认打开时，Escape 只取消最上层确认；原导入面板保留。安全标签支持左右方向键、Home 与 End。这里使用的是应用现有焦点管理组件，原型的原生 `dialog` 不是生产实现依赖。

当前 CDK 浮层不使用模态遮罩或焦点限制。眼睛提供随展开状态变化的可访问名称、`aria-expanded` 和 `aria-controls`；浮层有名称，读取及复制反馈为状态文字，错误使用 `role="alert"`，读取失败可重试。

## Do's and Don'ts

- **Do** 继续从现有主题变量和工作区样式取得全局视觉规则，局部尺寸以 `cdk.css` 为准。
- **Do** 分别表达管理员身份、当前工作区与当前可见视角；进入目标 CDK 后持续展示范围提示。
- **Do** 把可用次数、累计消耗、保存账号数分别说明，并在导入、追加、融合前展示余额变化。
- **Do** 保留原接码、邮件、代理和 Sub2API 配置能力，按当前工作区读取和保存。
- **Don't** 把原型顶部场景与角色选择器加入真实应用；真实身份来自后端会话，管理员视角切换属于已登录功能。
- **Don't** 从原型快照推断当前鉴权、数据或后端能力，也不要将本机合成验证写成生产账号验证。
- **Don't** 为扩展页面重定义全局色板、字体、侧栏和抽屉规范，或把完整 CDK 写入截图说明及长期文档。
