# CDK 扩展的设计系统记录

日期：2026-10-23。对象：本目录交互原型；以下记录描述实际样式和交互，不增加新的全局视觉身份。

## 继承依据与 token 映射

已对照根目录 `DESIGN.md`、`.impeccable/design.json`、`PRODUCT.md`，以及 `web/src/styles.css`、后加载的 `web/src/workspace.css`。原型延续石墨与蓝色工作台、176px 侧栏、连续概览带和细分隔线表格。字体沿用本机回退栈，无字体下载。

| 角色 | 现有系统 | 原型实际使用 |
|---|---|---|
| 主动作 / 悬停 / 选择 | `--green` / `--green-strong` / `--green-soft`，名称保留历史命名，实际为蓝色 | `--accent` / `--accent-strong` / `--accent-soft`；浅色 `#365edb` / `#294dbb` / `#eaf0ff`，深色 `#8daeff` / `#abc3ff` / `#293952` |
| 背景 / 表面 | `--page` / `--surface` | 同值继承；浅色 `#f3f5f8` / `#ffffff`，深色 `#131923` / `#1b2331` |
| 正文 / 辅助 / 边界 | `--ink` / `--muted` / `--line` | 浅深两套同值继承 |
| 成功 / 危险 / 警告 | `--success` / `--danger` / `--amber` | 同值继承，状态始终带可读文字 |
| 字体 / 数字 | IBM Plex Sans、Noto Sans SC、Segoe UI、Microsoft YaHei、sans-serif；`tabular-nums` | 正文 14px，按钮 13px，标签 12px，次要行数据 11px；标题 24px / 600，登录标题 34px；标识与 IP 使用既有等宽回退栈 |
| 形状 / 焦点 | 按钮 8px、表格 12px；2px 主色轮廓、3px 外偏移 | 同样使用；禁用透明度 `.48`，表格静态无抬升阴影 |

局部取值应保留为原型差异，不能写回全局 token：浅色 `--subtle: #f7f8fb` 比现有 `--surface-subtle: #f3f5f8` 更浅；警告底色使用 `#fff8e8` / `#342d23`，现有源码为 `#fff6df` / `#3b3326`。原型 `--shadow` 是完整的 `0 12px 40px rgb(20 34 57 / 14%)` 阴影，现有同名变量是供菜单和抽屉组合的颜色值，两者不能直接互换。原型遮罩也单独定义为 `--overlay`。

## 新增组件组合

| 组合 | 实际行为与视觉处理 |
|---|---|
| 次数变化预览 | 导入、追加、融合共用“当前 / 本次变化 / 操作后”三段等式；只有结果数字使用主蓝，导入同时显示新增、更新、重复和错误数量 |
| CDK 表与流水 | 管理列表使用脱敏标识、状态文字和次数列；详情承接累计消耗、余额、账号数及流水，区分余额、现存账号数和任务成功数 |
| 身份导航 | 复用工作台外壳，普通用户隐藏管理入口；顶部显示当前 CDK。场景选择及示例密钥明确属于原型工具 |
| 我的 CDK | 平面余额摘要与融合表单并置；来源验证后编辑输入会清除旧资格、等式和融合入口，确认及提交再次核对来源与目标 |
| Sub2API 配置 | 连接字段、目标分组与自动修复分区；自动修复默认关闭，开启后显示间隔与冷却字段；示例配置按当前 CDK 保存 |
| 安全中心 | 安全日志 / IP 黑名单使用文字标签和蓝色底线；异常提示可以进入日志，事件可打开拉黑表单，黑名单可解除 |
| 登录与封禁 | 登录使用普通表单及就地错误；封禁视图显示来源、时长及恢复时间，提供状态检查入口 |

抽屉使用原生 `dialog`，最大宽度 550px、贴右且无外圆角；确认弹窗最大宽度 470px、12px 圆角、距离窄屏边缘至少 16px。它们是本原型的局部尺寸，沿用现有层级方式，不替换现有业务抽屉的宽度。

## 响应与可访问性

- 内容最大宽度 1680px，默认水平留白 28px；1600px 起为 40px。现有工作区最大宽度为 1920px，此处更窄的阅读宽度仅用于原型。
- 1150px 以下隐藏 CDK / 任务表次要列，配置与余额布局改为单列；900px 以下侧栏改为顶部可换行导航；640px 以下水平留白 13px，筛选、主操作及输入按钮组换行，表格保留标识、状态或余额和详情入口。
- 页面最小宽度 320px；抽屉不超过视口。粗指针下已列出的按钮、导航、搜索和筛选控件至少 44px，表单与搜索输入为 16px。减少动态效果偏好有对应覆盖；没有新增入场动画。
- 提供跳到主要内容链接、表单标签、当前导航标识、状态文字与可见焦点。错误使用 `role="alert"`，登录输入关联错误说明；反馈提示使用 `role="status"` 和 polite live region。
- 原生模态框限制焦点、支持 Escape；打开后将焦点移入，关闭后恢复触发控件，控件已移除时回到当前导航。安全标签支持左右方向键、Home / End，并恢复新标签的焦点。

## 覆盖与边界

| 已确认规则 | 原型对应证据 | 生产接入仍需验证 |
|---|---|---|
| `(cdk_id, normalized_email)` 联合身份 | 同邮箱的两个 CDK 显示独立行、独立凭据说明，普通用户只见自己的记录 | 数据库唯一约束、凭据命名空间、全部接口和后台任务归属 |
| 首次新增扣一次 | 去重导入区分新增 / 更新，仅新增扣次；MFA 流转、零余额更新和重试不重复扣次 | 原子事务、并发幂等、失败恢复、已删除账号恢复规则 |
| 未消耗源 CDK 才能融合 | 已消耗后追加仍拒绝；合格来源整额转入并永久失效；编辑来源使旧预览失效 | 数据库锁、提交时重验、并发融合和会话撤销 |
| 个人 Sub2API 独立 | 不同 CDK 不继承配置，自动修复默认关闭 | 密钥存储、远端关联与后台修复隔离；原型不连接服务 |
| 管理员 IP 安全 | 失败日志、模拟告警 / 封禁、从事件拉黑及解除 | 可信客户端 IP、真实窗口限流、多进程一致性和管理员恢复路径 |

已核对 `.impeccable/review/cdk/checks.json`：32 项合成检查通过，8 场景 × 4 宽度无页面水平溢出，浏览器脚本错误为 0；另有 9 张截图。已比对其中桌面与手机 CDK 管理截图。深色抽样对比度为正文 14.02:1、辅助文字 7.19:1、蓝色文字 / 轻蓝表面 5.35:1；这些抽样不等于完整可访问性认证。完整执行范围见 [验证记录](verification.md)。

原型状态只在浏览器内存中存在，刷新或重置即恢复；身份、扣次、配置、封禁及连接测试反馈均为演示。密钥轮换、备注编辑、安全阈值编辑和本机解除封禁命令尚无交互流程。数据库、真实凭据、服务端会话、真实账号操作和网络防护按 [实施改造文档](implementation-plan.md) 后续接入。
